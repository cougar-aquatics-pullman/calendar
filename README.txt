COUGAR AQUATICS — MAC CALENDAR VERSION

Calendars used:
Cougar Aquatics Events Calendar -> Meets
Practices -> Practices
Club Events -> Club Events
Important Days -> Important Dates sidebar

FIRST TIME:
1. cd into this folder in Terminal
2. ./update-calendar
3. macOS may ask Terminal permission to control Calendar — click Allow.
4. python3 -m http.server 8000
5. Open http://localhost:8000

TO UPDATE LATER:
./update-calendar
Then refresh the browser.

Only title, date/time, location and category are exported. Descriptions, attendees, emails and attachments are not copied.
